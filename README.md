# -Multimodal-Deep-Learning-Based-Skin-Cancer-ClassificationThis-project-proposes
A multimodal deep learning framework for automated skin cancer classification using the Derm7pt dataset. The system integrates dermoscopic images, clinical photographs, and clinical metadata to identify five skin lesion categories: Nevus, Melanoma, Basal Cell Carcinoma (BCC), Seborrheic Keratosis (SK), and Miscellaneous (MISC). 

Official Derm7pt Dataset ---  http://derm.cs.sfu.ca?utm_source=chatgpt.com
ISIC Challenge Datasets  ---  https://challenge.isic-archive.com/data/?utm_source=chatgpt.com
